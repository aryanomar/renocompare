# 🏠 RenoCompare – Home Renovation Proposal Comparison Platform

## Problem Statement
Homeowners planning renovation work often receive multiple contractor proposals but struggle to compare scope, materials, timelines, and quoted work side by side.

## Key Features
- **Project Requirements Overview:** Displays target renovation budget, duration, and core scope items.
- **Contractor Profiles & Proposals:** View contractor experience, ratings, quoted work, and warranty.
- **Scope & Material Comparison Matrix:** Side-by-side matrix highlighting included/excluded scope items, lowest price, and fastest timeline.
- **Selection Status Workflow:** Filter and update proposals across *Under Review*, *Shortlisted*, *Selected*, and *Rejected* states.

## Tech Stack
- HTML5, CSS3 (Responsive Grid & Flexbox), Vanilla JavaScript (DOM Manipulation)
